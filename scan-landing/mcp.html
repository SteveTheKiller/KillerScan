Install KillerMCP

KillerMCP includes all 81 KillerTools utilities plus tools from supported Killer apps in one local connection. The installer detects KillerScan and registers that shared connection with supported agent clients.

  3. Open a new agent chat and ask. Available tools are discovered automatically.

What it can do

KillerMCP exposes all four headless KillerScan commands.

Identify the local networkReturn the active interface, local IPv4 address, subnet, gateway, and DNS server without scanning hosts.
Scan the networkRun bounded quick discovery or full fingerprinting and port checks.
Deep probe one hostInspect one IPv4 host, including ports 1 through 1024.
Look up MAC vendorsUse KillerScan's bundled offline OUI database without contacting a lookup service.

Data safety and permissions

KillerScan commands run on your computer. Local network identification does not probe other devices. A quick or full scan does send packets from your computer to the requested target, so review the target and scan type and scan only networks you are authorized to test.

The Cloudflare Worker never performs the local scan. Your MCP client and model provider can still receive the target and returned device data, so apply that provider's data handling rules.

How it works

KillerMCP is an open-source local runtime. It starts one MCP connection, detects installed Killer apps, and exposes only the adapters supported by those installed versions. For this page, it calls KillerScan with fixed timeouts, validates the target, and bounds the returned JSON.

The optional public endpoint is a separate open-source MCP server running as a Cloudflare Worker. Requests sent there are processed on Cloudflare. It offers web based KillerTools utilities but cannot reach your LAN or invoke KillerScan.

Current limits

Targets must be one IPv4 address or a CIDR from /22 through /32. Scans time out after 60 seconds and return no more than 100 discovered devices. Deep probes accept one IPv4 address.
